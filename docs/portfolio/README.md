# Portfolio images

Cover images for the tools in this repo. Every store name and number is sample data.

- `sales-desk.png`: who to call today, ranked by reorder timing, with A/R flags
- `ar-aging.png`: the weekly A/R report read from PDF and checked before it updates anything
- `data-pull.png`: the daily n8n pull that feeds the other tools

Source HTML is in `src/`. To re-render: open each file in a browser at 1600×1000 and screenshot.

**How to check them:** every row in the A/R image adds across and every column adds down to 7,575.00.
**Where they can go wrong:** they're pictures, not live data. If a tool changes, re-render the image.
