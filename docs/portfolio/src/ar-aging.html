A/R Aging Checker

The weekly A/R report, turned into a call sheet

QuickBooks emails an aging report every Monday. This reads the PDF, rebuilds it by customer and bucket, and only updates the call sheet if the numbers add up.
Python + Google Sheets
QuickBooks email (PDF)→Read by column position→Totals check→Call sheet + Slack DM
